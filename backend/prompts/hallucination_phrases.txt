# gpt-4o-transcribe 在长静音段或纯音乐段会"凭空生成"文字，典型是字幕组署名、
# 视频平台口播。这些假片段会被当成证据原文，必须剔除。
#
# 规则：
#   1. 以 # 开头的行是注释；
#   2. 其余一行一个短语，命中的片段会被整条丢弃；
#   3. 比对前会去掉空格和标点，所以"谢谢 观看"也能命中"谢谢观看"；
#   4. 短语是子串匹配，写太短会误伤正常对话，建议 3 字以上。
